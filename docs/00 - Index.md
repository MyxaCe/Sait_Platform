# Apex Capital Platform — документация

Монорепозиторий экосистемы международного брокера: маркетинговый сайт (готов), далее — интеграция с CRM, личный кабинет, веб-терминал.

## Быстрые факты

- **Стек**: Next.js 14 (App Router) · TypeScript strict · Tailwind (CSS-переменные) · Turborepo + pnpm · next-intl v4 · Serwist · Zustand · React Query · Zod
- **Прод**: VPS + Docker, деплой через GitHub CI/CD (в работе)
- **Команды**: `pnpm dev` · `pnpm build` · `pnpm test` · `pnpm --filter @broker/web test:e2e`
- Бренд-плейсхолдер: «Apex Capital». Технические идентификаторы (эндпоинты, ивенты, поля) — только английский.
